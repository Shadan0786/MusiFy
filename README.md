# MusiFy

A web-based music application built with JavaScript, HTML, and CSS.

## Overview

MusiFy is a modern music player and management application that provides a seamless listening experience with an intuitive user interface.

## Features

- 🎵 Music player with play, pause, and skip controls
- 📋 Playlist management
- 🎨 Clean and responsive user interface
- ⏱️ Progress tracking and duration display
- 🔊 Volume control
- 🎯 Search and filter functionality

## Tech Stack

- **Frontend**: 
  - JavaScript (62.6%)
  - HTML (37%)
  - CSS (0.4%)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Shadan0786/MusiFy.git
cd MusiFy
```

2. Open the application in your browser:
```bash
# Simply open index.html in your preferred web browser
open index.html
```

## Usage

1. Open `index.html` in your web browser
2. Load your music files or connect to a music source
3. Use the player controls to:
   - Play/Pause tracks
   - Skip to next/previous track
   - Adjust volume
   - Navigate through playlists
